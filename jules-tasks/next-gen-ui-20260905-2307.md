# snd3600-scanner Next-Gen UI & Features

## Context
We currently have a basic `snd3600-scanner.py` tkinter script that connects to a USB slide scanner (`/dev/videoX`). It applies color negative inversion with per-channel histogram stretching, zooming, and some manual sliders for exposure/contrast/brightness.

## Goal
Transform the application into a highly polished, intuitive, and feature-rich "top of the line" tool for slide scanning.

## Requirements
1. **Modernized UI**: 
   - Replace basic `ttk` widgets with a more modern framework if possible, or heavily theme the existing tkinter app (e.g. `sv_ttk` or `customtkinter`). 
   - The UI should be professional and intuitive, similar to high-end scanning software (VueScan, SilverFast).
   - Better layout for controls (e.g., collapsible panels for advanced settings).
2. **Color Profiles & Advanced Parameters**:
   - Implement "Color Profiles" (e.g., "Fuji Superia", "Kodak Gold", "Portra", "Slide Film", "B&W"). Each profile could apply specific curves or color shifts.
   - Add sliders for Color Temperature and Tint (White Balance).
   - Add a histogram display showing RGB channels and clipping warnings.
   - Add a "Save Profile" / "Load Profile" feature to save user-defined parameters.
3. **Workflow Improvements**:
   - Add a Batch scanning mode (auto-saving frames every X seconds, or a "Scan and Next" shortcut).
   - Hotkeys for quick adjustments (e.g., Arrow keys for zooming/sliders, Space to capture).
   - Non-destructive adjustments preview before saving.
4. **Code Structure**:
   - Refactor `snd3600-scanner.py` into a proper package if necessary, separating UI logic, image processing, and camera capture.

## Constraints
- Do not run Playwright, Cypress, or any headless-browser/e2e/UI test runner — they routinely hang or crash this sandbox and kill the session. Verify UI behavior via static/type checks and unit tests only, and describe manual verification steps in the PR description instead.
- Never run destructive git commands (`git reset --hard`, `git checkout -- .` / `git restore .`, `git clean -fd`/`-fdx`, unresolved `git stash`, force-push, history rewrite on pushed commits). Never discard uncommitted changes. Commit work incrementally and frequently so nothing is lost if the session stops early.
